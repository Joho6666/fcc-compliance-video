## 一、核心结论：图解驱动，不是角色驱动

- 场景检测 180 秒只有 **2 次硬切**（130.6s、132.9s）：画面是**连续的图解动画**，每隔几秒在同一画面上"加一个元素"（再画一个方框、再出一个箭头、再亮一个关键词），不是换镜头。
- 角色出镜极少：开头没有角色，中段只有一个小骑士图标代表"分词器"，**结尾才出现一个二次元女生头像贴纸**（黑色虚线描边）配"关注"。
- 所以"动漫感"主要来自：**扁平卡通图标 + 粗描边 + 圆体粗标题 + 可爱的比喻**（用"刀"表示切分），不是整片都有人物。

## 三、讲解手法

1. **权威开头**：以"人民日报把 Token 翻译成词元"+"140 万亿"这种大数字开场（背书 + 体量）。
2. **先问再答**：电脑浏览器窗口里打出「Token 是什么？」当黑板。
3. **用自己的名字举例**："我要关注，点赞小白debug"被切成块——例子很具体，还带自家品牌。
4. **形象比喻**：分词器 = 三把刀。
5. **图解递进**：文本 → 编号（010110）→ AI 大模型，一步一步加；输入 Token 列 → AI 大模型 → 输出 Token 列。
6. **反复回到同一张图**，只改局部（例如缓存命中，同一张对话图上加一道绿色弧线）。

## 四、对 FCC 9:16 版的启示（据此调整原方案）

1. **以图解为主、角色为辅**：主体做"流程图逐步生长"，角色（原创"认证小哥"）只在开头、转折、结尾出现，做引导和反应，不要每个镜头都站在画面里。
2. **图标用代码画，不用 AI 生图**：参考视频的图标极简、风格高度统一，用 SVG 画（文档、建筑、路由器、芯片、日历、清单、放大镜）比 AI 出图更统一、更清晰、零费用，还能做逐笔动画。AI 生图只用于主角（需要一致性）。
3. **连续动画而不是硬切**：同一画面上逐步加元素，镜头切换次数比 v3 少得多，改成"每 2–3 秒加一个元素"。
4. **底色用浅色方格纸**，不用深色全屏照片——这是和 v3 最大的区别，也是"科普讲解"感的来源。
5. **字幕**：底部小条深灰圆角框，一行一句，与参考一致（9:16 下放在安全区内）。
6. **可信度元素**：引用来源。用文字标注"来源：Reuters / FCC 公开文件"，**不放路透社截图**（版权）；FCC 文件页面可以引用，但需另行下载（本次没有下载，不做）。
7. **结尾**：「关注 + 第一时间告诉你」+ 主角挥手，对应参考的头像贴纸。
8. **比喻**：参考用"刀 = 分词器"。FCC 版用"认证报告 = 体检报告，实验室 = 体检医院"。
